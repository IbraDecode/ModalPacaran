# Testing

```bash
npm test
```

Cakupan:
- `src/utils/__tests__/dateKey.test.ts`: formatter tanggal + kalkulasi streak.
- `src/services/__tests__/copyEngine.test.ts`: output copy dinamis.
- `src/app/__tests__/guard.test.tsx`: guard router mengalihkan ke intro ketika flag belum selesai.
